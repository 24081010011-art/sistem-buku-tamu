# Sistem Buku Tamu Digital

  ## Deskripsi
  Sistem Buku Tamu Digital adalah aplikasi web berbasis PHP dan MySQL yang digunakan untuk mencatat data tamu secara digital. Aplikasi ini membantu proses pencatatan kunjungan menjadi lebih terstruktur, cepat, dan mudah dikelola.
  
  ## Fitur Utama
  
    ### Login dan Logout
    * Login menggunakan username dan password
    * Session login
    * Role Admin dan User
    
    ### Manajemen Data Tamu
    * Menampilkan data tamu
    * Menambah data tamu
    * Mengubah data tamu
    * Menghapus data tamu
    
    ### Kelola User
    * Menampilkan daftar pengguna
    * Mengaktifkan dan menonaktifkan akun pengguna
    
    ### Dashboard
    * Menampilkan ringkasan data tamu
    * Menampilkan jumlah kunjungan dan pengguna
  
  ## Teknologi yang Digunakan
  * PHP Native
  * MySQL / MariaDB
  * HTML
  * CSS
  * Bootstrap 5
